TamperGuard

A client-side integrity monitor. It watches the regions you mark and locks or reports the page the moment they're modified — DevTools edits, injected scripts, or fake "edit-and-screenshot" tampering.

Plain HTML →

No build, no framework. Edit the protected box in DevTools and watch it lock.

React →

Guarding a static region while React state keeps re-rendering freely.

Vue →

Same idea with v-pre to keep Vue off the guarded block.

Break-it test suite →

An automated battery of tamper attacks — proof the guard reacts, and ignores benign extensions.

Reminder: this is a deterrent and a signal, not a security boundary. Anything that must be trustworthy still has to be validated on the server.
